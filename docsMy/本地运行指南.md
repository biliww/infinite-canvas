# 本地运行指南

## 技术栈概览

| 层级 | 技术 | 端口 |
|------|------|------|
| 前端 | Next.js 16 + React 19 + TypeScript + Tailwind CSS v4 + Ant Design v6 | 3000 |
| 后端 | Go 1.25 + Gin + GORM | 8080 |
| 数据库 | SQLite（默认）/ MySQL / PostgreSQL | — |

**前端代理**：Next.js 的 `web/src/app/api/[...path]/route.ts` 会将所有 `/api/*` 请求转发到后端（默认 `http://127.0.0.1:8080`），通过环境变量 `API_BASE_URL` 可修改后端地址。

---

## 方式一：Docker 一键运行（推荐，无需本地安装 Go/Node）

### 前置条件

- [Docker](https://docs.docker.com/get-docker/) 已安装并运行

### 步骤

```bash
# 1. 进入项目根目录
cd /Users/wangpenglong/projects/github/infinite-canvas

# 2. 从模板创建环境配置文件
cp .env.example .env

# 3. （可选）修改 .env 中的默认账号密码等配置
#    ADMIN_USERNAME=admin
#    ADMIN_PASSWORD=infinite-canvas
#    JWT_SECRET=infinite-canvas
#    DATABASE_DSN=data/infinite-canvas.db  # SQLite，数据存在项目 data/ 目录

# 4. 使用本地构建文件启动（Dockerfile 会构建前后端产物）
docker compose -f docker-compose.local.yml up -d --build
```

### 验证

浏览器访问 `http://localhost:3000`，使用 `.env` 中配置的账号密码登录。

### 其他 Docker 命令

```bash
# 查看容器日志
docker compose -f docker-compose.local.yml logs -f

# 停止容器
docker compose -f docker-compose.local.yml down

# 使用预构建镜像（如果有发布版本）
docker-compose up -d
```

### docker-compose.local.yml 说明

```yaml
services:
  app:
    image: infinite-canvas:local        # 本地镜像名
    build:
      context: .
      dockerfile: Dockerfile            # 使用项目根 Dockerfile 构建
    env_file:
      - .env                            # 读取 .env 配置
    volumes:
      - ./data:/app/data                # 持久化 SQLite 数据库文件
    ports:
      - "3000:3000"                     # 映射宿主机 3000 端口
    restart: unless-stopped
```

## 方式二：本地源码运行（适合开发调试）

### 前置条件

| 工具 | 版本要求 | 验证命令 |
|------|---------|---------|
| Go | >= 1.25 | `go version` |
| Node.js | >= 20 | `node --version` |
| npm / pnpm / bun | npm >= 10 / pnpm >= 8 / bun >= 1.3 | `npm --version` / `pnpm --version` / `bun --version` |

本项目前端 lock 文件为 `bun.lock`，优先推荐使用 **bun**。也可以用 **pnpm** 或 **npm**（会忽略 bun.lock，各自生成自己的 lock 文件）。

### 步骤

#### 1. 创建环境配置文件

```bash
cd /Users/wangpenglong/projects/github/infinite-canvas
cp .env.example .env
```

#### 2. 启动后端（Go）

新开一个终端：

```bash
cd /Users/wangpenglong/projects/github/infinite-canvas

# 启动 Go 服务，默认监听 8080 端口
# 配置读取 .env 文件中的 PORT、DATABASE_DSN 等
go run main.go
```

启动成功的日志：

```
[GIN-debug] Listening and serving HTTP on :8080
```

**说明**：
- 后端默认使用 SQLite，数据库文件生成在 `data/infinite-canvas.db`
- 首次启动会自动创建管理员账号（基于 `.env` 的 `ADMIN_USERNAME` / `ADMIN_PASSWORD`）
- `main.go` 还会启动定时同步提示词的任务

#### 3. 启动前端（Next.js）

另开一个终端：

```bash
cd /Users/wangpenglong/projects/github/infinite-canvas/web

        # 方式 A：使用 bun（推荐，匹配项目 lock 文件）
        # 安装 bun（如果尚未安装）
        npm install -g bun
        bun install
        bun run dev

        # 方式 B：使用 pnpm
        pnpm install
        pnpm dev

        # 方式 C：使用 npm
        npm install
        npm run dev
```

启动成功的日志：

```
 ▲ Next.js 16.2.3
 - Local: http://localhost:3000
```

**说明**：
- 前端开发服务器运行在 `http://localhost:3000`
- 所有 `/api/*` 请求通过 Next.js Route Handler（`web/src/app/api/[...path]/route.ts`）自动代理到后端 `http://127.0.0.1:8080`
- 如后端端口不是 8080，可设置环境变量：`API_BASE_URL=http://127.0.0.1:其他端口`
- 默认允许所有来源的 dev 访问（方便手机或局域网测试）

### 验证

浏览器访问 `http://localhost:3000`，用 `.env` 中的账号密码登录。

## 环境变量说明

配置项来自项目根目录 `.env` 文件：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ADMIN_USERNAME` | `admin` | 管理员账号，首次启动自动创建 |
| `ADMIN_PASSWORD` | `infinite-canvas` | 管理员密码 |
| `JWT_SECRET` | `infinite-canvas` | JWT 签名密钥（生产环境务必修改，留空会自动生成随机密钥） |
| `JWT_EXPIRE_HOURS` | `168` | 登录态有效期（小时），7 天 |
| `PORT` | `8080` | Go 后端监听端口 |
| `API_BASE_URL` | `http://127.0.0.1:8080` | 前端代理后端地址（只在启动前端时使用） |
| `STORAGE_DRIVER` | `sqlite` | 数据库类型：`sqlite` / `mysql` / `postgres` |
| `DATABASE_DSN` | `data/infinite-canvas.db` | 数据库连接字符串 |
| `LINUX_DO_AUTHORIZE_URL` | `https://connect.linux.do/oauth2/authorize` | Linux Do OAuth 地址（目前无需配置） |
| `LINUX_DO_TOKEN_URL` | `https://connect.linux.do/oauth2/token` | Linux Do Token 地址 |
| `LINUX_DO_USERINFO_URL` | `https://connect.linux.do/api/user` | Linux Do 用户信息地址 |

### 切换到 MySQL / PostgreSQL

修改 `.env`：

```ini
# MySQL 示例
STORAGE_DRIVER=mysql
DATABASE_DSN=user:password@tcp(127.0.0.1:3306)/infinite_canvas?parseTime=true

# PostgreSQL 示例
STORAGE_DRIVER=postgres
DATABASE_DSN=postgres://user:password@127.0.0.1:5432/infinite_canvas?sslmode=disable
```

## Docker 构建流程说明（供参考）

`Dockerfile` 分三个阶段：

1. **web-build**：使用 `oven/bun:1.3.13` 构建 Next.js 静态产物
2. **api-build**：使用 `golang:1.25-alpine` 编译 Go 后端为二进制
3. **runtime**：使用 `oven/bun:1.3.13` 作为运行镜像，同时启动 Go 后端和 Next.js

```dockerfile
# 最终镜像启动命令：
CMD ["sh", "-c", "PORT=8080 /app/server & cd /app/web && HOSTNAME=0.0.0.0 PORT=3000 bun run start"]
```

- Go 后端监听容器内部 8080，不对外暴露
- Next.js 监听 3000 对外提供服务，通过 Route Handler 反向代理 `/api/*` 到内部 Go 服务

## 常见问题

**Q：前端页面空白 / 接口报错 "接口连接失败"**

确认 Go 后端已启动且端口正确。如果后端端口不是默认 8080，需要设置 `API_BASE_URL`：

```bash
# 在 web/ 目录启动前设置
export API_BASE_URL=http://127.0.0.1:你的端口
bun run dev
```

**Q：bun 安装失败或网络慢**

使用 pnpm 或 npm 替代，或配置 bun 的 registry：

```bash
# bun 使用国内镜像
bun install --registry=https://registry.npmmirror.com
```

**Q：启动后登录提示 "账号或密码错误"**

检查 `.env` 中的 `ADMIN_USERNAME` 和 `ADMIN_PASSWORD`。如果是已有数据库，修改 `.env` 不会同步更新已有用户的密码——需要删除数据库文件重新启动：

```bash
rm -f data/infinite-canvas.db
go run main.go
```

**Q：如何拉取提示词库？**

启动成功后，访问 `http://localhost:3000/admin/prompts`，点击同步按钮即可从 GitHub 开源项目拉取提示词。
